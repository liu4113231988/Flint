# 燧石能否替代有道词典桌面版

评估于 2026-11-22，基于 Windows x64 版 Flint3，代码版本 `2010e9f`。

3.5.3 更新了原评估中的五条功能路径。手输和取词共用原文查询，精确释义排在前缀补全前面，排序邻词从结果中移除。空结果区分未收录和缺少词库。同一词可查看多个来源，来源名显示在展开的释义中。三种取词入口均在点击「翻译原文」后发送文本。添加生词等待写入完成，失败时保留备注和颜色并提示重试。下文保留原评估与验收条件。

**结论：有条件达标。** 已备好词库、主要在 Windows 上阅读英文的用户，可以用燧石完成离线查词、中文反查和本地生词整理。若要求刚装好就能查、在不同入口查同一短语得到一致首选、查不到时能辨明原因，当前还未达标。依赖双语例句、复习计划或跨端单词本的用户也无法完整迁移。

判断先看一次查词能否得到可信结果、遇到问题能否恢复，再看功能覆盖。有道的公开桌面帮助用来确定典型任务，部分页面属于历史版本，本次未对两个客户端做同机性能或译文质量排名。[有道桌面查词说明](https://cidian.youdao.com/5.0/help/deskdict5beta/description/01.html) · [有道单词本帮助](https://cidian.youdao.com/wordbooktip5.html)

## 功能合理性

| 用户任务 | 当前行为与判断 | 建议的验收条件 |
| --- | --- | --- |
| 在搜索框输入读到的词或短语 | 输入即查、取消旧请求适合连续键入。手输会去掉空格、撇号和连字符，划词先按原文精确查。真实词库中，手输路径把 `take off` 变为 `takeoff`，首项为 `take ... off`；精确查原文首项为 `take off`。导入的 MDX 还按保留空格的原词做前缀匹配。**优先修正。** | 用同一个已收录短语，分别手输、划选、在浮窗编辑，原词条都排第一。保留普通前缀和通配符搜索。 |
| 判断是否真的查到了 | 内置英文匹配从排序索引的插入位置向后取词。输入 `applx` 得到 `apply` 等候选，界面没有说明它们是邻近词。无数据便携版中，英文空结果也没有专门的缺库提示。用户很难决定该改拼写还是装词库。**优先修正。** | 分别用拼错的词、有效前缀、无可用词库验收。能辨认邻近建议、正常补全和缺库三种状态；缺库时可找到数据准备或 MDX 导入入口。 |
| 在别的应用里读词和句子 | 划词图标需主动开启，点击才查；无法读取选区时有截图 OCR 路径。AI 已开启且本地未命中时，点图标会将原文发往配置的接口；划词快捷键和 OCR 则需再点「翻译原文」。本地优先合理，但同一段文字是否外发取决于入口。 | 开启 AI 时说明自动发送的触发条件。用同一段未收录文字分别走图标、快捷键和 OCR，核对发送时机；取消后旧结果不覆盖新选区。[划词行为与运行条件](selection-icon.md) |
| 用专业词典读熟词的新义 | 导入的 MDX 可以调序，但内置源排在前面，同拼写只保留一个来源。两本词典都收录某词时，专业释义可能无法查看。 | 内置词库和专业 MDX 各收录同一拼写、不同释义，用户可在该词结果中找到专业释义及其来源。 |
| 把生词留到下次看 | 本地词本支持释义、备注、颜色及筛选。添加时界面立即收起，数据库写入异常只记日志；收藏失败也可能看起来像已完成。 | 成功收藏后重开仍可见。模拟写入失败时保留本次输入，显示原因并允许重试。 |

英文匹配及跨源排序可追到 [查询入口](../Flint3/ViewModels/MainViewModel_Flint.cs)、[CSF 匹配](../Flint3.Data/Csf/CsfReader.cs)、[MDX 匹配](../Flint3.Data/Mdx/MdxSource.cs) 和 [多词源归并](../Flint3.Core/Query/WordQueryService.cs)。收藏反馈见 [添加生词控件](../Flint3/Controls/AddToGlossaryControl.xaml.cs) 和 [词本写入](../Flint3.Data/GlossaryDataAccess.cs)。

## 功能完善性

| 替代场景 | 达到的范围 | 影响迁移的边界 |
| --- | --- | --- |
| 日常英汉阅读 | 本地英文释义、中文释义、音标、词形和系统语音朗读；真实词库抽查 `apple` 首项正确 | 系统朗读依赖已安装语音。词条缺少独立的双语例句和搭配检索，辨析多义词时仍需其他资料。MDX 仅支持部分格式和文本，无法补入 MDD 音频。 |
| 由中文找英文 | 装好中文索引后可按精确词或前缀反查；真实库中「苹果」首项为 `apple` | 面向从短中文释义找英文词。拼音、分词和简繁转换均超出现有索引范围。[中文反查设计](chinese-lookup-decision.md) |
| 读外文段落 | 独立翻译面板、划词和截图识别可接续使用 | 整句翻译依赖用户配置的兼容模型接口，OCR 依赖 Windows 语言包。需要开箱即用翻译或整份文档翻译的用户仍有缺口。[翻译设置与要求](llm-translation-requirements.md) |
| 长期积累词汇 | 本机收藏、备注、筛选和内置考试词表支持回看 | 未发现有道单词本迁移、跨设备同步或按记忆进度提醒复习的入口。已有多年词本的用户应先验证旧词能否带入，再决定迁移。 |

**处理顺序**：先让原文精确命中、拼写未命中和缺库状态可信，再补收藏失败反馈、外发提示和同词多来源查看。例句与词本迁移分别服务于深度阅读和长期学习，可在前述查词路径验收后按目标人群安排。

## 验证依据与剩余实测

三套现有测试全部通过，Core 160 项、Data 162 项、Dict 12 项。另重新构建 Flint.Cli，使用本机真实 CSF 和同目录 ZHX 查询。可在仓库根目录用下列命令复核两条短语路径和未命中样例，`match takeoff` 模拟手输入口清洗后的参数。

```powershell
$dict = (Resolve-Path Flint3/Data/stardict.csf).Path
dotnet run --project tools/Flint.Cli -- $dict query 'take off' 3
dotnet run --project tools/Flint.Cli -- $dict match takeoff 3
dotnet run --project tools/Flint.Cli -- $dict match applx 3
```

浮窗焦点、多显示器缩放、浏览器和 PDF 的划选、OCR 准确率、系统朗读及真实模型译文仅核对实现和依赖，仍待桌面实测。发布前宜用同一词、短语和句子在可选文字网页与扫描 PDF 各走一遍，并在无词库、无模型配置的便携版上核对恢复提示。
