# 划词图标与浮窗翻译

有道词典桌面版支持拖选或双击文字，并提供划词图标、直接显示结果和快捷键等入口。燧石采用点击图标打开结果的交互，图标沿用燧石品牌。 [有道划词释义帮助](https://cidian.youdao.com/huaci/detail_qa.html) · [有道桌面版功能说明](https://cidian.youdao.com/5.0/help/deskdict5beta/description/09.html)

- 在「设置 → 显示划词图标」或托盘菜单开启。升级时沿用原自动划词开关。
- 在其他应用拖选或双击选中文字后，图标显示在鼠标选区末端附近，默认靠右下方。临近屏幕边缘时翻到另一侧。图标显示时保留原应用焦点。
- 点击图标后先查本地词典。开启 AI 翻译后，可以点击「翻译原文」，将选区原文发往配置的接口。译文、失败原因和重试入口在同一浮窗显示。
- 点击别处、切换前台窗口或等待约 15 秒会收起图标。新的选区替换旧的选区，关闭结果窗或修改输入会取消当前翻译。
- 划词快捷键（默认 `Ctrl+Alt+D`）和屏幕取词（默认 `Ctrl+Alt+S`）直接打开结果窗。需要 AI 翻译时点击「翻译原文」。
- 无法通过 Windows UI Automation 读取选区的控件可使用屏幕取词。按热键冻结当前显示器画面，再拖选区域或单击文字。按 `Esc` 或点击「取消」关闭覆盖窗。OCR 需要安装相应的 Windows 语言包。
